# 📘 SOC Overview

## What is a SOC?
A **Security Operations Center (SOC)** monitors, detects, investigates, and responds to cybersecurity threats in real time.

## SOC Objectives
- Continuous monitoring
- Threat detection
- Incident response
- Risk reduction

## SOC Analyst Levels
- **L1:** Monitoring, alert triage
- **L2:** Investigation, root cause analysis
- **L3:** Threat hunting, advanced response

## Key Takeaways
- SOC is defensive security
- Alerts must be analyzed before escalation

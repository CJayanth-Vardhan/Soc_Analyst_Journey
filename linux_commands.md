# 🐧 Linux Commands for SOC Analysts

## Common Commands
| Command | Purpose |
|------|------|
| ls | List files |
| cd | Change directory |
| cat | Read files |
| grep | Search text |
| tail | View logs |

## Important Log Paths
- `/var/log/auth.log`
- `/var/log/syslog`

## SOC Usage
- Log analysis
- Incident investigation
- Process monitoring

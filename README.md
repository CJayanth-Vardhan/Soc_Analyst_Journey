# 🛡️ SOC Analyst L1 – Overview

## 📌 What is a Security Operations Center (SOC)?
A **Security Operations Center (SOC)** is a centralized team responsible for **24/7 monitoring, detection, analysis, and response** to cybersecurity threats. The SOC protects an organization’s systems, networks, and data from cyberattacks.

---

## 👨‍💻 Who is a SOC Analyst L1?
A **SOC Analyst Level 1 (L1)** is an **entry-level Blue Team professional** and the **first line of defense** in the SOC.

The primary responsibility of a SOC Analyst L1 is to:
- Monitor security alerts  
- Perform initial investigation  
- Identify false positives  
- Escalate confirmed incidents to higher-level analysts  

SOC Analyst L1 follows **Standard Operating Procedures (SOPs)** and predefined **incident response playbooks**.

---

## 🔍 Key Responsibilities
- Monitor alerts from **SIEM and security tools**
- Perform **alert triage** and initial analysis
- Analyze logs from **Windows, Linux, and network devices**
- Identify common threats such as:
  - Brute-force attacks
  - Malware activity
  - Phishing attempts
  - Suspicious login behavior
- Classify alerts based on **severity and priority**
- Escalate confirmed incidents to **SOC Analyst L2**
- Document investigation steps and findings clearly

---

## 🗓️ Daily Activities
- Review SIEM alerts and dashboards
- Investigate suspicious events using logs
- Validate alerts using threat intelligence
- Close false positives with justification
- Escalate true positives with evidence
- Update tickets and incident documentation

---

## 🧠 Skills Required
- Basic networking knowledge (TCP/IP, DNS, HTTP/HTTPS)
- Linux and Windows fundamentals
- Log analysis skills
- Understanding of common cyberattacks
- Knowledge of the incident response lifecycle
- Basic understanding of **MITRE ATT&CK**
- Strong documentation and attention to detail

---

## 🧰 Tools Commonly Used
- SIEM platforms (e.g., Wazuh)
- Linux command-line tools
- Log monitoring and analysis tools
- Network monitoring tools
- Threat intelligence platforms

---

## 🔁 Incident Handling Process (L1)
1. Alert received from SIEM  
2. Initial analysis of alert and logs  
3. Validation (false positive or true positive)  
4. Severity classification  
5. Escalation to L2 (if required)  
6. Documentation and ticket update  

---

## 🎯 Importance of SOC Analyst L1
SOC Analyst L1 plays a **critical role in early threat detection**. Accurate alert triage and timely escalation help prevent minor security events from becoming major incidents.

---

## 📈 Career Progression
- **SOC Analyst L1** – Monitoring and triage  
- **SOC Analyst L2** – Investigation and response  
- **SOC Analyst L3** – Threat hunting and advanced defense  

---

## 🔹 Summary
A **SOC Analyst L1** monitors security alerts, performs initial investigations, and escalates incidents to protect organizations from cyber threats.
